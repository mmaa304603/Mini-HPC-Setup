Disabling nodes before shutdown
_________________________________________________________________________________________________________________________
New procedure since 7th Nov 2023
_________________________________________________________________________________________________________________________

1. Disabling nodes
2. This time there the following error when running - "globus-connect-server node list" command
An API Error Occurred
HTTP status: 400
code:        Error
message:     invalid_grant
3. A logout and login solved it
globus-connect-server logout
globus-connect-server login localhost
4. sudo yum update \*globus\* \*myproxy\* \*gsi-openssh\*
5. globus-connect-server endpoint key convert -c cc7fff7e-4350-4b09-9356-83ebe7ddad5b
6. globus-connect-server node setup 
7. globus-connect-server node update --enable 75cdac56-0547-469b-9754-95a76394e141
8. Check globus-connect-server node list 
All done !













_________________________________________________________________________________________________________________________
Older process
_________________________________________________________________________________________________________________________

1. globus-connect-server node list
2. globus-connect-server node update --disable 75cdac56-0547-469b-9754-95a76394e141
disable all nodes in the list one by one using this command and correct node_ID

Resuming service

1. globus-connect-server node setup -c cc7fff7e-4350-4b09-9356-83ebe7ddad5b
use "Globus_Connect_Info.txt" file to find relevant info.
The ID is Client_ID and not Node_ID and use the secret when prompted.

2. globus-connect-server node update --enable 75cdac56-0547-469b-9754-95a76394e141
to bring back the other node.
