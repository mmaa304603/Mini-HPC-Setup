Add a given machine as a node to an existing endpoint:
1. Copy the deployment-key.json file from the previous machine, in this case Sol.
2. Run: globus-connect-server node setup --client-id "cc7fff7e-4350-4b09-9356-83ebe7ddad5b"
where the last segment is the client-id generated when one registers a node as a server initially on globus's developer website: https://auth.globus.org/v2/web/developers
For present project details are in "Globus_Connect_Info.txt".

3. Run: globus-connect-server login localhost
This returns a link. Use the link and login using HPCC admin details with which the server was initially created on https://auth.globus.org/v2/web/developers
